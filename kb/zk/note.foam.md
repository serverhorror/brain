# zk

zk is a plain text note-taking assistant that leverages the power of the command line.

## Windows Installation

```powershell
curl.exe -L -O https://github.com/zk-org/zk/releases/download/v0.15.4/zk-v0.15.4-windows-x86_64.tar.gz
```

> [!NOTE]
> The environment variable `XDG_CONFIG_HOME` **MUST** be set to `%USEPROFILE%\.config`.
>
